오늘은 경기도 용인 보라동에서 출발해 서울 평창동, 연희동, 역삼동을 거쳐 다시 용인으로 돌아오는 하루 일정을 모바일 전용 웹앱으로 구현한 **`Drops, Lines & Tiro`**의 AI 협업 개발일지를 공유하려고 합니다.

이 앱은 2026년 12월 8일 화요일의 실제 당일치기 여정을, 번들링이나 별도 빌드 과정 없이 스마트폰 브라우저에서 바로 사용할 수 있는 정적 브로슈어로 구성했습니다. 네 방향의 행선지를 좌우로 넘기고, 필요한 환승 정보와 미션을 바텀시트에서 확인할 수 있습니다.

### 1. 프롬프트 1단계: "너무 길어서 보기 어려워" — 세로 타임라인에서 스와이프 브로슈어로

처음 AI에게 일정 데이터를 주고 웹앱 초안을 생성했을 때는 모든 이동 구간과 행선지가 위에서 아래로 길게 이어지는 단일 타임라인 형태였습니다. 정보는 빠짐없이 들어 있었지만, 막상 이동 중에 스마트폰 한 손으로 스크롤하며 보기에는 호흡이 너무 길었습니다.

여기서 첫 번째 구조 개편 프롬프트를 던졌습니다.

> *"너무 길어서 보기 어려워. 미션 타임라인을 상단 고정으로 두고, 김창열 화가의 집·우동카덴·박서보미술관·티로 앱 각 페이지를 좌우로 스와이프해서 행선지를 바꾸는 포스터형 브로슈어로 고치자. 시작할 때는 사전 점검 모달이 아래에서 위로 올라오게 하고, 각 포스터를 누르면 환승과 미션 전문이 담긴 긴 디테일 뷰가 열리게 해줘."*

이 한 번의 구조 전환으로 앱의 사용자 경험(UX)이 완전히 달라졌습니다.

1. **시작 바텀시트 모달 (`Bottom-Up Modal`):** 앱을 열면 아래에서 위로 부드럽게 올라오는 시트에서 명함 지참, 테이블링 원격 줄서기, 티로 백그라운드 녹음 테스트 같은 출발 전 체크리스트와 용인 보라동 왕복 광역버스(4101번·5001-1B번) 요약을 먼저 점검합니다.
2. **상단 고정 4단 미션 타임라인:** `01 김창열` ➔ `02 우동카덴` ➔ `03 박서보` ➔ `04 티로앱` 4개 핵심 노드만 상단에 고정해 현재 위치를 직관적으로 보여줍니다.
3. **한 화면(`100dvh`) 포스터 스와이프 & 디테일 뷰:** 메인 화면은 CSS `scroll-snap-type: x mandatory`를 적용해 스크롤 없이 한 장의 포스터처럼 꽉 차게 넘어가고, 자세한 대중교통 환승 스텝과 도슨트 녹음 가이드는 카드를 터치했을 때 열리는 디테일 시트로 분리했습니다.

---

### 2. 프롬프트 2단계: 추상적인 색을 걷어내고 실제 건축 물성과 리브랜딩 고증하기

구조가 잡힌 뒤에는 시각적 완성도를 끌어올릴 차례였습니다. 초기 버전의 CSS 테마는 '물방울 = 파란 글씨', '일식당 = 어두운 남색', 'AI 앱 = 쨍한 블루와 빨간 점멸등'처럼 다소 추상적이고 전형적인 웹 템플릿에 가까웠습니다.

그래서 AI에게 각 공간의 실제 건축 마감재와 조명, 그리고 브랜드의 최신 철학을 엄밀하게 조사해 디자인 시스템으로 번역하도록 요청했습니다.

| 행선지 | 초기 추상 테마 | 실제 공간·브랜드 고증 디자인 시스템 (`themes.css`) |
| :--- | :--- | :--- |
| **김창열 화가의 집** (평창동) | 베이지 도트 배경 + 파란 텍스트 | 우규승 건축가의 원설계와 리모델링 물성을 반영한 **화강석·종석 웜 스톤(`#E7E2D8`)** 질감, 지붕 **원형 천창(Oculus)에서 쏟아지는 자연광 후광**, 투명 물방울 렌즈 배지 |
| **우동카덴 연희점** (연희동) | 어두운 남색 노렌 + 붉은 도장 | 정호영 셰프 매장의 정갈하고 밝은 식사 분위기를 살린 **히노끼 내추럴 우드(`#F6F1E7`)**와 깊은 다시마 **츠유 다크 브라운(`#2C221E`)** 조합 |
| **박서보미술관** (연희동) | 한지 배경 + 붉은 세로 줄무늬 | 최문규 교수가 설계한 건물의 **3층 반투명 유리 큐브 확산광(`#F7F7F5`)에서 지하 2층 블랙박스(`#242426`)로 이어지는 건축적 명암 대비**와 노출 콘크리트 세로 결(묘법 리듬) |
| **티로(Tiro) After Meeting** (역삼동) | 쨍한 파란색 + 깜빡이는 빨간 녹음등 | 2026년 4월 티로 리브랜딩 철학(*"화려함을 덜고 조용히 곁을 지키는 속기사"*)을 고증한 **고요한 미색 종이(`#FAF9F6`) + 속기사 차콜 잉크(`#1F2328`) + 은은하게 숨 쉬는 웜 세이지(`#5B6E65`) 인디케이터** |

특히 티로(Tiro) 카드에서 자극적인 빨간색 녹음 점멸 애니메이션을 걷어내고, 로마의 웅변가 키케로 곁을 지키던 속기사 티로의 정체성을 담아 2.8초 주기로 은은하게 호흡하는 **웜 세이지 인디케이터**로 바꾼 순간 포스터 전체의 품격이 한층 차분하고 단단해졌습니다.

### 3. 빌드 도구 없는 순수 웹 표준 아키텍처

이 프로젝트는 야외 이동 중 스마트폰 사파리나 크롬에서 즉시 열려야 하므로, 무거운 번들러나 외부 프레임워크 없이 순수 웹 표준(HTML5, CSS3, Vanilla JavaScript) 4개 파일만으로 구성했습니다.

```text
drops-lines-tiro/
├── index.html   # 100dvh 뷰포트 뼈대 및 2종의 바텀시트 모달 구조
├── themes.css   # 4대 공간 건축 물성 디자인 토큰 및 스와이프 스냅 레이아웃
├── data.js      # 평창동·연희동·역삼동 대중교통 환승, 티로 미션, 체크리스트 데이터
└── app.js       # 슬라이드·탭 양방향 동기화, 디테일 뷰 동적 렌더링, localStorage 영속화
```

현장에서 데이터를 잃어버리지 않도록 `localStorage`를 연결했습니다. 행선지 미션 완료 여부와 출발 전 체크리스트 선택 상태를 브라우저에 저장하며, 시작 바텀시트의 **초기화** 버튼으로 저장된 상태를 모두 지울 수 있습니다.

또한 상세 바텀시트는 네이버지도·카카오맵 위치 검색, 우동카덴 테이블링 원격 줄서기, 박서보미술관 공식 웹사이트, 티로 애프터미팅 초대장을 각 행선지 맥락에 맞춰 바로 열 수 있도록 연결했습니다.

### 4. 마치며

이번 작업을 통해 AI와 함께 코딩할 때 가장 강력한 무기는 단순히 "코드를 짜달라"고 하는 것이 아니라, **정보의 밀도를 줄이는 UI 전환(긴 스크롤 ➔ 포스터 스와이프 + 바텀시트)**을 명확히 지시하고, **실제 공간의 건축 재료와 브랜드의 철학이라는 구체적인 맥락을 디자인 토큰으로 번역**하게 만드는 과정이라는 점을 다시 한번 체감했습니다.

이제 [GitHub Pages에 배포된 모바일 브로슈어](https://shiene1010.github.io/drops-lines-tiro/)를 스마트폰 홈 화면에 추가해 두고, 평창동과 연희동의 미술관, 그리고 역삼동 티로 모임 현장에서 직접 테스트해 볼 일만 남았습니다.
